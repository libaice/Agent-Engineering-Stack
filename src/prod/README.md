# Production Stack 


## 六件套与可验证产出

| #    | 主题     | 核心机制                           | 跑出来的硬数字                                       |

| 05   | 韧性     | 重试退避 + 断路器 + 多级降级       | 断路器开路后死依赖调用归零,服务不中断                |
| 06   | 部署     | FastAPI + 信号量背压 + 负载聚合    | 50 并发 100% 成功,吞吐/p99 全量化                    |
