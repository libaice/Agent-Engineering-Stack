#  数据库选型表

| 方案 | 最适合 | 优点 | 风险 |
| --- | --- | --- | --- |
| **FAISS** | 本地实验/高性能库 | 快、灵活 | 不是完整数据库 |
| **Chroma** | 本地 RAG demo | 简单 | 生产能力有限 |
| **pgvector** | 企业业务系统 + RAG | SQL、事务、权限、metadata 方便 | 超大规模时要小心调优 |
| **Milvus** | 大规模向量检索 | 专用、高性能、多索引 | 运维复杂度更高 |
| **Qdrant** | 自托管向量服务 | 过滤强、工程体验好 | 需要单独服务 |
| **Pinecone** | 托管云服务 | 省运维、上线快 | 成本、供应商绑定 |
| **OpenSearch** | 搜索 + RAG | BM25/hybrid/search 生态强 | 向量能力和调优复杂 |
